A Lucide glyph, used everywhere an icon appears — the open substitute for SF Symbols, which cannot be redistributed.

```jsx
<Icon name="search" size={20} />
<Icon name="chevron-right" size={17} color="var(--text-tertiary)" />
```

Sizes: 17 inline with body text, 20 inside controls, 24 in tab bars. Stroke stays at 1.75 so glyphs match the type's optical weight. The page must load `https://unpkg.com/lucide@latest/dist/umd/lucide.min.js` once.
